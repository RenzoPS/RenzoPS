## 🚀 Qué hago

Llevo servicios desde un repositorio vacío hasta correr dentro de sistemas empresariales con requisitos estrictos de correctitud y trazabilidad. Hoy trabajo en el sector bancario, dentro de un equipo de 7 personas, sobre sistemas en producción.

- ☕ **Backend:** microservicios en Java y Spring Boot — modelo de dominio, API REST, migraciones, contenedores y tests. Node con Express cuando el proyecto lo pide.
- 🔐 **Auth y seguridad:** autenticación por token, control de acceso por roles, CORS y las cosas del OWASP Top 10 que efectivamente rompen APIs.
- 💾 **Datos:** relacional o NoSQL según el problema, no según la costumbre. Filtrado dinámico que compone en vez de multiplicar endpoints, caché donde ayuda, y N+1 detectado antes de producción.
- 🎨 **Frontend:** React y TypeScript sobre esas mismas features — formularios, modales, tablas — así el trabajo llega end to end en vez de frenar en la API.
- 🤖 **IA:** ingeniería, no research. Agentes, RAG, servidores MCP y pipelines de automatización. Los uso todos los días y sé dónde se rompen.
- 🧪 **Tests:** unitarios, de integración y basados en propiedades. Documentación al día y Git como corresponde: ramas por feature, commits que se explican solos, review antes de mergear.

Lo que me importa del código que escribo: **errores que nombran el problema**, acceso a datos que no se cae con una combinación de filtros que nadie previó, y un README que te deja clonar y correr sin preguntarle a nadie. No agrego una dependencia cuando el stack existente ya resuelve el problema.

**Abierto a trabajo freelance y por contrato.**
